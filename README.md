# Data Structures & Algorithms in C++

A comprehensive collection of practical implementations, data structure exercises, and algorithmic problems written in C++.

## 📁 Repository Contents

| File Name | Description | Key Concepts |
| :--- | :--- | :--- |
| `count_element_functions.cpp` | Counts occurrences of elements in arrays using custom functions. | Arrays, Functions, Loops |
| `find_max_array.cpp` | Finds the maximum element and its index within an array. | Array Traversal, Max Algorithm |
| `piecewise_function.cpp` | Implements piece-wise mathematical functions based on user conditions. | Conditional Logic, Math Functions |
| `pointer_array_operations.cpp` | Demonstrates pointer operations, searching, swapping min/max, and checking palindromes. | Pointers, Memory Addressing, Palindrome Check |
| `recursive_search.cpp` | Searches for a target value in an array using a recursive strategy. | Recursion, Array Search |
| `shapes_structures.cpp` | Manages 2D geometry using nested structures for Points and Circles, calculating distances and spatial testing. | Structs, Nested Structures, Geometry, `<cmath>` |
| `square_matrix_operations.cpp` | Performs matrix operations on 2D square arrays. | 2D Arrays, Matrix Manipulation |
